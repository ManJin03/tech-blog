# 关于本站

**ByteForge** 是一个关注系统编程、异构计算与工程实践的个人技术博客。

所有文章以 Markdown 撰写，由自建的轻量静态站点生成器构建——源码就在本仓库的 `build.js` 里，不到 300 行，欢迎阅读与改造。

## 写作范围

- **系统编程**：C/C++、并发、内存模型、性能优化
- **异构计算**：昇腾 Ascend C、CUDA、算子开发
- **工程实践**：构建系统、调试技巧、代码设计
